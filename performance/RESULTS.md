# 课程机实测结果

本次在 4 vCPU、8 GiB 的 openEuler 虚拟机上使用 openGauss 6.0.2。两个版本从相同的 1 万名学生、600 个教学班和 10 万条选课开始。每个并发档先预热，再测三轮。每轮同时满足读 P95 ≤ 500 ms、写 P95 ≤ 1000 ms、技术错误率 < 0.1% 和三项 SQL 对账为零才通过。

| 版本及流量 | 最高达标 → 首次失守 | 达标档 req/s¹ | 达标档读 / 写 P95² (ms) | 失守档读 / 写 P95² (ms) |
|---|---|---:|---:|---:|
| V2 均匀 | 32 → 64 | 242.12 | 298.3 / 356.4 | 705.2 / 817.2 |
| V2 热门班 | 32 → 64 | 172.23 | 336.3 / 766.7 | 763.0 / 966.2 |
| V3 均匀 | 32 → 64 | 318.52 | 217.4 / 265.6 | 747.3 / 808.7 |
| V3 热门班 | 32 → 64 | 193.49 | 294.5 / 719.3 | 765.5 / 1037.3 |

¹ 三轮吞吐量中位数。² 分别取三轮中最高的读、写 P95。各轮 P50/P95/P99、业务拒绝和技术错误分别见原始记录。

| 流量 | 最高达标并发档变化 | V3 首次失守档的观测 |
|---|---:|---|
| 均匀 | +0 | 数据库平均 212% CPU，API 平均 57% CPU，采样时最多 0 个未获授锁 |
| 热门班 | +0 | 数据库平均 178% CPU，API 平均 50% CPU，采样时最多 11 个未获授锁 |

四组共测 137,029 次 HTTP 请求。技术错误 0 次，业务拒绝 0 次；每轮独立查询席位计数、同课重复选课及学分汇总，三项差异合计 0。CPU 以一个逻辑核为 100%。锁数是周期抽样，可能漏掉短等待。

## 索引与关联查询

五种读取都得到相同结果集。两项候选索引占用 7,274,496 字节。在这组实验中，候选索引下名单查询中位数由 2.416 ms 变为 3.674 ms，1000 行写入由 98.521 ms 变为 113.552 ms。正式迁移保留原有索引。开课列表的先修关系以一条批量查询读取，20 条及 100 条每页均由真实数据库契约测试核验。
